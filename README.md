# 📍 GPS to Excel Exporter

Une application web simple et open-source pour générer, visualiser et exporter des données GPS quotidiennes vers un fichier Excel.

## 🚀 Fonctionnalités
- **Génération de test** : Simulez un parcours GPS pour tester le pipeline.
- **Visualisation interactive** : Affichez les points sur une carte.
- **Export Excel** : Téléchargez les données (Timestamp, Latitude, Longitude) en un clic.

## 🛠️ Installation locale
1. Clonez le projet : `git clone https://github.com/digitalphenotypelab-oudina/gps-to-excel.git`
2. Installez les dépendances : `pip install -r requirements.txt`
3. Lancez l'app : `streamlit run app.py`
